# todo-list
Hack Club Vibes YSWS

A simple command-line to-do list written in Python.

## Usage

From `/home/runner/work/todo-list/todo-list`:

```bash
python3 todo.py add "Buy milk"
python3 todo.py list
python3 todo.py done 1
python3 todo.py undone 1
python3 todo.py remove 1
python3 todo.py clear
```
